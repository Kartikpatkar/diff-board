DiffBoard is a clean, developer-focused code comparison utility that operates entirely offline in your browser. Designed for speed and simplicity, DiffBoard helps you identify differences between source code files, logs, config properties, and structured data payloads with a clean, responsive layout.

Whether you are comparing API responses, reviewing database queries, or analyzing template code, DiffBoard provides high-contrast visual cues without sending any data over the network.

### Key Features

* **Flexible Diff Layouts:** Switch between split side-by-side and unified single-column views on demand to review changes in the format you prefer.
* **Safe Format & Minification:** Format, minify, validate, or sort key hierarchies safely using robust, tokenizer-based state machines that preserve string values, URLs, and comments.
* **Offline Syntax Highlighting:** Highlights code keywords and markup syntax locally using embedded static stylesheets for both dark and light workspace themes.
* **Smart Search Navigation:** Find text matches inside the comparison view and navigate through them sequentially with next/prev chevrons that scroll matches to the center of your screen.
* **Direct File Import:** Drag and drop files directly into the editor panels or use the import action button to load files quickly without manual copying.
* **Consolidated Actions:** Copy the full diff, a standard unified patch, only added (+) lines, or only removed (-) lines, or export comparison cards directly to TXT and HTML files.
* **Session & Configuration Restore:** Automatically saves your active editor contents, ignore configurations, and workspace settings so you do not lose your work on refresh.
* **Accidental Loss Guard:** Features built-in confirmation dialogs to prevent accidental clearing of code inputs during active workflows.

### Privacy First

DiffBoard does not collect, store, or transmit any user data. All files, code inputs, and diff renderings are processed completely locally within your browser context, ensuring your sensitive development data remains private.
